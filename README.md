# 给照片一个清楚的去处

[简体中文](README.md) | [English](README.en.md)

照片从手机、相机和扫描件进来，哪些还没整理、哪些要修、哪些值得放进主题或影集？这个 Skill 让 AI 先了解你的目标与习惯，再为你搭建一个能看照片、追踪进度和逐项确认的摄影工作台。

它不会把作者的家庭分类、影集主题或审美偏好套到你身上。你的意见会保留原话和落实结果；有跨照片、跨批次价值的经验，经你采用和验证后，才会成为以后可复用的规则。

## 安装和开始

```bash
npx -y skills add Ptothez/photo-workbench-skill -g --all
```

然后对 AI 说：

> 帮我做一个摄影工作台。我想保留家庭记录，也想慢慢做主题影集。先和我确认照片从哪里来、哪些要留、怎样选片，以及哪些事情需要我判断。

AI 应先读取你已有的资料，只问影响设计的缺口。确认方案后，再创建你的工作台。

## 做出来应当怎样用

- 打开概况，看到新照片、整理与修图进度，以及下一步由谁做。
- 先选主题或分类，再逐张看照片；直接放大，准确定位原文件，不在一堆文件里自己找。
- 所有需要你决定的事情集中在一个入口：看图、读一个具体问题、接受建议或写修改意见，保存后进入下一项。
- 具体照片意见落实到具体照片；流程和审美经验另行提炼。原话、处理结果、候选规则、验证与生效状态分开保存。

## 包里有什么

包含搭建与验收的 Skill、反馈闭环协议、一个可改造的本地界面，以及 Python 标准库运行的参考服务。`bootstrap.py` 只接受已确认的需求 profile，并拒绝覆盖已有目录。默认由你通知后按批执行，不自行创建持续扫描任务。

这不是一个内置 AI 模型的自动修图软件。实际看图、归类、归档和规则提炼由你的 AI Agent 在授权范围内完成；它需要把真实结果接入工作台。空页面、接口通过或文件名猜测，都不能算完成选片。

## 环境与验证

需要支持 Skills 的 AI 客户端和 Python 3.10+。界面没有构建依赖。RAW、PSD 和高位深扫描件应由 Agent 根据你的文件格式配置合适的预览工具，并验证实际图像。

```bash
python skills/photo-workbench/scripts/test_runtime.py -q
```

测试使用合成资料，检查确认后创建、禁止覆盖、反馈保存、并发冲突和下次上下文读取。真实文件定位、桌面应用窗口和视觉效果仍须在使用者自己的系统上验收。

仓库没有真实照片、聊天、人物资料、私人规则、数据库、存储地址或凭据。数据留在你选择的本地目录；本地服务只绑定回环地址。
