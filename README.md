# 给照片一个清楚的去处

[简体中文](README.md) | [English](README.en.md)

照片从手机、相机和扫描件进来，哪些还没整理、哪些要修、哪些值得放进主题或影集？这个 Skill 让 AI 先了解你的目标与习惯，再为你搭建能看照片、追踪进度和逐项确认的摄影工作台。

你的分类、留存边界和审美由你决定。意见保留原话和落实结果；有跨照片、跨批次价值的经验，经你采用和验证后，才会成为以后可复用的规则。

## 安装和开始

```bash
npx -y skills add Ptothez/photo-workbench-skill -g --all
```

然后对 AI 说：

> 帮我做一个摄影工作台。我想保留家庭记录，也想慢慢做主题影集。先和我确认照片从哪里来、哪些要留、怎样选片，以及哪些事情需要我判断。

AI 应先读取已有资料，只问影响设计的缺口。确认方案后才创建工作台，不预填作者的分类或私人规则。

## 日常怎样用

- 概况展示新照片、整理与修图进度，以及下一步由谁做。
- 按自己的主题或分类进入照片集，再逐张看图、放大、准确定位原文件。
- 审核只有一个入口，分为「现在要决定」「待补充」「可选复查」「等待线索」。能由 Agent 核实的事情留给 Agent；不是所有信息缺项都要你逐张批准。
- 看图、读具体问题、接受建议或写修改意见，保存后进入下一项。已保存、待执行和完成分别记录。
- 照片意见落实到照片；流程和审美经验保留来源、提炼候选、本人采用、多场景验证后供以后使用。

## 浏览器或 Windows 桌面

本地浏览器方式需要 Python 3.10+，服务使用标准库。可选 Windows 独立桌面程序把窗口和本地服务一起管理，断连后恢复；可以从桌面和任务栏重开。它不建立照片监听或定时整理任务。

桌面方式需要 Windows x64、.NET Framework 4.8 编译器、Python 和 WebView2 Runtime。构建时从官方 NuGet 下载固定版本 SDK 并核对 SHA-256；仓库只发布源码。创建和安装步骤见 [快速开始](skills/photo-workbench/references/quickstart.md) 与 [Windows 桌面说明](skills/photo-workbench/references/windows-desktop.md)。

## 能力边界和验证

这是支持 AI Agent 执行工作的 Skill 和本地界面。真实看图、归类、预览生成、复制验证和归档由 Agent 在授权范围内完成，并把结果接入工作台。空页面或文件名猜测不能算完成选片。RAW、PSD 和高位深扫描件需配置合适的预览工具。

```bash
python skills/photo-workbench/scripts/test_runtime.py -q
```

合成测试检查确认后创建、禁止覆盖、四类审核分流、反馈保存、冲突拒绝、下次上下文读取、缓存更新和桌面选项。桌面源码另经 Windows 编译；实际文件定位、固定图标重开、预览和中断恢复仍须在使用者机器验收。不同 AI 客户端与操作系统不视为已经全部验证。

仓库不包含真实照片、聊天、人物资料、私人规则、数据库、存储地址或凭据。数据留在你选择的本地目录；服务只绑定回环地址。
